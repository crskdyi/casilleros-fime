# e-Lockers · Architecture

React 19 + TypeScript, TanStack Start, Tailwind CSS 4. Netlify deploys the TanStack app via its Vite plugin. The existing reservation API remains on Render; do not add another backend or database without an explicit requirement.

## Key directories

- `src/routes/index.tsx`: home route, mounts the reservation application.
- `src/routes/__root.tsx`: Spanish HTML shell and product/share metadata.
- `src/components/locker-app.tsx`: functional UI, loading, selection, building, zoom and reservation state.
- `src/lib/lockers.ts`: API client, strict validation, building definitions and field types.
- `src/styles.css`: warm neutral and green palette, DM Sans/Manrope, responsive layouts and reduced motion.
- Adjacent `*.test.ts(x)` files: Vitest and Testing Library coverage.
- `src/components/ui`: scaffolded shared primitives; `src/router.tsx`: router defaults.

## Conventions and decisions

Keep UI copy in Spanish, use functional components and hooks, and preserve API field names `id`, `edificio`, `en_uso`. Building 5 has 100 IDs (5001–5100); building 1 represents Polideportivo and has 224 (1001–1224). Do not enforce a whole-response length of 100. Reject invalid records and duplicate IDs, without filling availability from inferred data. Absent IDs are disabled placeholders explicitly marked as lacking data.

Native buttons supply keyboard selection and visible focus. Occupied lockers are disabled. Zoom is bounded to 100–200% and resettable in Building 5. Preserve schematic positions when filtering occupied lockers. Never store state in localStorage, sessionStorage or a service-worker cache. All persistent reservation state belongs to the external API.

Reserve only through POST with `{ id }`. Only HTTP success permits confirmation. Preserve selection after failure, including HTTP 400. Refresh availability after success; separately show refresh failure without undoing confirmed success. Avoid mutations against the live API during verification. Query request versions prevent stale results from overwriting the current state.

`src/routeTree.gen.ts` is generated by TanStack; do not hand-edit it. Scripts: `pnpm test`, `pnpm run typecheck`, `pnpm run build`. In hosted agent runs, follow platform restrictions on running validation commands; the build pipeline performs validation.
